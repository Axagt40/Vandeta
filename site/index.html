Four things it does that stock Bruce does not

The rest of the feature list lives in the README.

Radios

Four radios, all working

CC1101 sub-GHz, nRF24 2.4 GHz, WiFi and BLE — with the CC1101 serialized against the display on the SPI bus they share, and a Packet Monitor fed by all four.

Infrared

2,858 IR codes

The Flipper libraries for TV, AC, fans, audio, projectors and LEDs, with brand, remote and family sweeps in the IR Suite, plus hand-written RCA and NEC42 encoders.

Developer Options

A USB console over the same cable

ui, move and press drive the menus and print the screen you land on; file, errors, mem and livepatch cover the rest. One switch arms it.

Fit

Built for this board only

One target, so the encoders, the battery, the 320 × 170 layout and the shared SPI bus are tuned rather than guessed. The CC1101 and the nRF24 are not simultaneous.

From download to running in three steps

The image is pre-merged, so it is one write at offset 0x0.

  1. Download the image

    vandeta.bin plus its .sha256 from the release you want. Any OS; the browser flasher needs Chrome or Edge.

  2. Flash it at 0x0

    Use the flasher over Web Serial, or esptool.py write_flash 0x0 vandeta.bin. The offset is always 0x0.

  3. Drive it from the PC

    Turn on Config → System Config → Developer Options, then send ui over the same cable and read the screen back.

Straight from the console

serial · 115200 · Developer Mode on 
ui
ui down
mem
errors
livepatch apply hello console.log('hi')

Every command answers immediately — none waits on a modal banner. Try the same thing in the live console.
