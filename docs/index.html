Vandeta is custom firmware for the LilyGo T-Embed CC1101, built on Bruce 1.16.1. Everything Bruce does, plus a USB console that lets a PC drive the menus, radios, files and scripts — with no WiFi, no reflash and no extra hardware.

What is on top of Bruce

Bruce's menus, apps, radios and script ecosystem are unchanged and still there. This is the extra layer.

Developer Options

A USB console over the same cable

ui, move, press drive the menus and print the screen you land on; file, errors, mem, proc and livepatch cover the rest. One switch arms it.

Sub-GHz

CC1101 that shares the display's SPI bus

A Flipper-style Frequency Analyzer, a wardriver that records whole bursts and replays them verbatim, and a subghz console path for headless testing.

nRF24

Pseudo-promiscuous 2.4 GHz capture

CRC off, auto-ack off, degenerate addresses on every pipe, channel hops and RGB-remote presets — with capture buffers in PSRAM so WiFi and BLE still fit.

Packet Monitor

One dashboard, four taps

WiFi, BLE, nRF24 and sub-GHz feed the same table, with filters, per-radio counters, CSV export and PCAP export of captured frames.

Infrared

Universal remote, 2,858 codes

The Flipper libraries for TV, AC, fans, audio, projectors and LEDs, twelve brand AC encoders, and hand-written RCA and NEC42.

BLE

A radar for what is advertising

A live, RSSI-sorted table with Apple Continuity types decoded and a distance estimate, plus capture & replay and a GATT client.

WiFi

MITM that reaches WPA2 clients

ARP spoofing, DNS spoofing and HTTP interception on the encrypted station link, exposed to menus and to scripts.

BadUSB

HID that iOS and macOS accept

USB footprint, layouts with import/export, timing, a payload manager, and a BLE keyboard that advertises one complete HID payload.

JavaScript

Scripts that reach the radios

arpSpoof, dnsSpoof, httpInterceptor, nrf24, scriptFolder and the rest — with hot reload from the console.

From download to driven in three steps

The image is pre-merged, so it is one write at offset 0x0.

  1. Download the image

    vandeta.bin plus its .sha256 from the latest release. Any OS; the browser flasher needs Chrome or Edge.

  2. Flash it at 0x0

    Use the flasher over Web Serial, or esptool.py write_flash 0x0 vandeta.bin. Wrong offset, wrong boot.

  3. Drive it from the PC

    Turn on Config → System Config → Developer Options, then send ui over the same cable and read the screen back.

Straight from the console

serial · 115200 · Developer Mode on 
ui
ui down
mem
errors
livepatch apply hello console.log('hi')

Every command answers immediately — none waits on a modal banner. Try the same thing in the live console.
